# Emad Portfolio

## التشغيل
1. افتح Terminal داخل المجلد.
2. شغّل `npm install`
3. شغّل `npm start`
4. افتح `http://localhost:3000`

## إضافة مشروع
افتح `public/projects.js` وانسخ أحد عناصر المشروع وعدّل title/category/description/image/tech/demo/github.
ضع صور المشاريع داخل `public/images` واكتب المسار مثل `/images/project.jpg`.
